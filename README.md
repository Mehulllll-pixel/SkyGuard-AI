# SkyGuard: AI-Powered Intruder Detection Drone

An AI-based drone surveillance system that uses object detection to identify intruders in real-time and alerts the user.

## Features
- Drone video feed processing
- YOLOv5-based object detection
- Face recognition for authorized personnel
- Alert system with audio/email

## Requirements
- Python 3.x
- OpenCV
- PyTorch
- YOLOv5

## How to Run
1. Install requirements
2. Run `drone_control.py` to start the drone and stream
3. Detection runs automatically on the feed
